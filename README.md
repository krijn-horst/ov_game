# OV Game

Een spel gebaseerd op GTFS-data van het openbaar vervoer.

## Over dit project

Dit project gebruikt GTFS (General Transit Feed Specification) data om een spel te bouwen rond het openbaar vervoer. Denk aan dienstregelingen, routes, haltes en real-time data als basis voor de gameplay.

## Status

🚧 In ontwikkeling

## GTFS-data

GTFS-bestanden bevatten onder andere:
- `stops.txt` — haltes en stations
- `routes.txt` — lijnen/routes
- `trips.txt` — ritten
- `stop_times.txt` — dienstregelingtijden
